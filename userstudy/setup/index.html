连接答卷收集

完成一次 Google 授权和部署后，参与者即可在独立网页填写。答卷保存在你的私有 Google Sheet，参与者无需登录 Google。

1. 新建 Apps Script 项目

打开 Google Apps Script，点击 New project（新建项目），命名为 SWIM User Study。

2. 粘贴脚本并保存

点击“复制脚本”，用完整内容替换 Apps Script 中 Code.gs 的默认代码，然后保存。

3. 运行 setupStudy 并授权

在编辑器顶部的函数下拉菜单选择 setupStudy，点击 Run（运行），按提示选择 Google 账户并完成授权。

运行成功后，执行日志会显示私有答卷表链接。保存这个链接，之后可随时查看数据。

4. 部署为 Web app

  1. 右上角 Deploy（部署） → New deployment（新建部署）。
  2. 点击类型选择旁的齿轮图标，选择 Web app（网页应用）。
  3. Execute as（执行身份）：Me（我）。
  4. Who has access（谁可以访问）：Anyone（任何人）。
  5. 点击 Deploy，复制以 /exec 结尾的 Web app URL。

5. 把 Web app URL 发给 Codex

Codex 会接入网站，检查匿名访问和真实保存，然后开启正式收集。

在哪里看数据

Responses 保存完整提交的答卷。每个视频的排序列用 B>A>C 表示从最自然到最不自然。

Sessions 保存匿名会话的已完成题数、最后连接时间、恢复次数和状态：active（页面保持打开）、paused（页面离开前报告暂停）、submitted（已提交）。长时间无连接且未提交的会话可能中断；关闭浏览器时的暂停记录不保证送达。

同一设备和浏览器可恢复进度；换设备或清除浏览器数据后无法自动关联。不要公开答卷表或私有方法对应表。
